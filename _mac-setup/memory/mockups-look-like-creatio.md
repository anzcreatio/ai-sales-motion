Mock-ups of Creatio screens (storyboards, concept pages, build plan wireframes) must look like Freedom UI: use `apac-sc-motion/standards/mockup-kit/freedom-ui-mock.css` and its README rules. Blue #004fd6 for actions, orange only for the logo, Montserrat, native cards, chips, tabs and fields, screens light in both themes.

**Why:** Yokogawa storyboard, 20 Nov 2026. The first version used our own orange styling and read as a website. Renzo: "use this as lesson to improve future mockups so they are more creatio like".

**How to apply:** start every mock-up from the kit; after the demo is built, swap mock-ups for real screenshots. Related: [[build-plan-before-build]].
