# 20-minute discovery card: template v0.2 (generic, both tracks)

> **One page, filled live.** The SC leads the questions; the AE takes notes on this card.
> Blocks follow the call order. **★ = must fill** (the minimum if the call isn't recorded).
> Tick, circle and write **their exact words in "quotes"**; no prose.
> After the call, paste this card (+ transcript if recorded) into the shared Claude project → Brief, go/no-go score, one-pager.
> Legend: ✔ true for them · ✘ not true · ? unclear
